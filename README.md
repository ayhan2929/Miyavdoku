# MiyavDoku

Android için renkli, kedi temalı blok bulmaca oyunu.

## Proje durumu

Bu depo temiz bir başlangıçtır. Eski proje dosyaları kullanılmayacaktır.

## İlk hedef

- 9×9 oyun tahtası
- Şekil yerleştirme
- Satır, sütun ve 3×3 alan temizleme
- Puan ve en iyi puan takibi
- Hamle kalmadığında oyun sonu
